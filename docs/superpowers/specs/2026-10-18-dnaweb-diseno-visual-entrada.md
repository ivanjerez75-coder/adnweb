# DNAweb: diseño visual del SaaS (entrada del usuario, 2026-10-18)

> Este texto lo escribió el usuario, tal cual. Es la base del Plan 3 (interfaz). Todavía no es un documento de diseño revisado.

## 1. Identidad visual
- **Nombre:** DNAweb.
- **Subtítulo:** Business Intelligence Platform.
- **Colores:**

| Uso | Color |
|---|---|
| Gris oscuro | `#393939` |
| Teal | `#0F766E` |
| Fondo | `#F5F5F5` |
| Superficie | `#F3F3F3` |
| Bordes | `#DADADA` |

- **Estilo:** minimalista, empresarial, limpio y basado en datos. Nada de negro con neones morados ni estética genérica de IA. Tiene que parecer un producto profesional de inteligencia empresarial.

## 2. Dashboard principal
Es la pantalla que aparece al entrar. Sirve para analizar un negocio rápidamente y recuperar análisis anteriores. Contenido:
- Cabecera "WORKSPACE / OVERVIEW".
- Titular "Business intelligence, simplified." y el texto "Analiza negocios digitales y descubre cómo funcionan."
- Campo "Introduce una URL para analizar" y el botón "+ New analysis".
- Lista "Recent analyses", con el enlace "View all →". Cada análisis muestra nombre, "Business profile" y la fecha relativa.

## 3. Navegación
Barra lateral fija en escritorio y menú adaptado en móvil. Secciones:

| Sección | Para qué |
|---|---|
| Overview | Dashboard |
| Analyze | Nuevo análisis |
| My analyses | Historial |
| Competitors | Fase futura |
| Market intelligence | Fase futura |
| Settings | Cuenta |

Las funciones futuras no deben mostrarse como disponibles si todavía no existen.

## 4. Pantalla de análisis
Un campo central para introducir la URL. Contenido:
- Encabezado "NEW ANALYSIS" y titular "Understand the business behind any URL.".
- Texto: "Introduce una web para descubrir su modelo de negocio, analizar las señales públicas disponibles y generar un informe estructurado."
- Botón "Analyze website →".
- Pie: "Public information · Evidence-based analysis".

## 5. Diseño del informe
Apariencia de dashboard analítico: un resumen arriba y secciones bien separadas.
- **Cabecera:** nombre, dominio y "Business report".
- **"Business overview":** descripción, propuesta de valor, público y cómo genera ingresos.
- **Tarjetas de resumen:**
  - Monthly traffic. Si no hay dato: "—" con "Requires reliable data".
  - Revenue estimate. Si no hay dato: "—" con "Not yet established".
  - Business model.
  - Data confidence.
- **"Business profile":** Value proposition y Monetization.
- **"Evidence & insights":** hallazgos con sus fuentes, explicación e implicaciones. Las oportunidades no verificadas se etiquetan como **hipótesis**.

## 6. Componentes
- **Tipografía:** sans serif moderna y legible.
- **Botones:** verde petróleo para las acciones principales, grises para las secundarias.
- **Tarjetas:** fondo blanco, bordes finos y radios moderados.
- **Espaciado:** generoso, con la información agrupada por secciones.
- **Iconos:** sencillos y consistentes.
- **Gráficos:** solo si aportan información verificable.
- **Tablas:** para comparaciones y datos que necesiten precisión.
- **Animaciones:** discretas, sobre todo en carga y transiciones.
- **Responsive:** dashboard completo en escritorio y navegación simplificada en móvil.
